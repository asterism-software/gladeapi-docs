Glade API exposes product details, search results, seller profiles, customer reviews, third-party offers, deals, and sales or stock estimates through one normalized contract. REST, GraphQL, and MCP share the same validation, caching, output schemas, and unit accounting on plans that include each interface.

## How Glade API Works

Every endpoint accepts a marketplace `domain` parameter. Each operation defines its own required inputs, such as an ASIN, GTIN, Amazon URL, search phrase, seller ID, or category ID. Responses are normalized JSON objects rather than raw HTML.

<Steps>
  <Step title="Create an API key">
    Sign up at [gladeapi.com](https://gladeapi.com/auth/login?next=/dashboard) and generate a reveal-once API key from your dashboard.
  </Step>
  <Step title="Authenticate your request">
    Pass your key in the `API-KEY` header (or as a Bearer token) on every call.
  </Step>
  <Step title="Choose your interface">
    Use REST (`/api/amazon/*`) on every plan. Paid plans also include GraphQL (`/api/graphql`) and MCP (`/api/mcp`).
  </Step>
  <Step title="Pick a marketplace">
    Add `?domain=US` (or UK, CA, DE, FR, IT, ES, AU, IN, MX, BR, JP, PL) to target any of the 13 supported Amazon marketplaces.
  </Step>
</Steps>
