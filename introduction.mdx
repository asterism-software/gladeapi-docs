Glade API gives you a single, unified gateway to normalized Amazon data. Whether you are building a price monitor, a product research tool, an AI shopping agent, or an e-commerce application, the same contract covers products, search, offers, reviews, sellers, deals, estimates, and more across 13 Amazon marketplaces.

## Three interfaces, one contract

REST, GraphQL, and MCP share the same underlying data model, authentication, caching, and unit accounting. The Hobby plan includes REST; paid plans also include GraphQL and MCP.

<Tabs>
  <Tab title="REST">
    The REST interface is the fastest way to get started. Pass your parameters as query strings and receive a normalized JSON response.

    ```bash
    curl "https://gladeapi.com/api/amazon/product?asin=B0D1XD1ZV3&domain=US" \
      -H "API-KEY: YOUR_GLADE_API_KEY"
    ```

    Every REST endpoint maps to a single Amazon data operation. See the [API Reference](/api-reference/product) for the full list of endpoints, parameters, and response schemas.
  </Tab>
  <Tab title="GraphQL">
    The GraphQL interface lets you request exactly the fields you need in a single round trip. POST your query to `/api/graphql` with your API key in the header.

    ```bash
    curl -X POST "https://gladeapi.com/api/graphql" \
      -H "API-KEY: YOUR_GLADE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "query": "query { amazonProduct(input: { asin: \"B0D1XD1ZV3\", domain: US }) { title price { value currency display } } }"
      }'
    ```

    The GraphQL schema mirrors every REST operation and supports authenticated introspection through the same `POST` endpoint. Each request must select exactly one root operation.
  </Tab>
  <Tab title="MCP">
    The MCP (Model Context Protocol) interface exposes all 17 Glade API operations as strongly-typed JSON-RPC tools at `/api/mcp`. It is designed for AI agents and LLM orchestration frameworks that support the MCP standard.

    ```bash
    curl -X POST "https://gladeapi.com/api/mcp" \
      -H "API-KEY: YOUR_GLADE_API_KEY" \
      -H "Content-Type: application/json" \
      -H "Accept: application/json" \
      -H "MCP-Protocol-Version: 2026-07-28" \
      -H "MCP-Method: tools/call" \
      -H "MCP-Name: get_amazon_product" \
      -d '{
        "jsonrpc": "2.0",
        "id": 1,
        "method": "tools/call",
        "params": {
          "name": "get_amazon_product",
          "arguments": { "asin": "B0D1XD1ZV3", "domain": "US" },
          "_meta": {
            "io.modelcontextprotocol/protocolVersion": "2026-07-28",
            "io.modelcontextprotocol/clientInfo": { "name": "curl", "version": "1.0.0" },
            "io.modelcontextprotocol/clientCapabilities": {}
          }
        }
      }'
    ```

    Each tool includes a machine-readable schema your agent can use to discover parameters and response shapes at runtime. See [Concepts: Interfaces](/concepts/interfaces) for a full tool listing.
  </Tab>
</Tabs>

## 13 Marketplaces

Pass the `domain` parameter to target any of the 13 supported Amazon marketplaces. Glade API selects the corresponding Amazon host and preserves marketplace-local currency data in a consistent response shape.

| Domain | Marketplace | Currency |
|--------|-------------|----------|
| `US`   | amazon.com        | USD |
| `UK`   | amazon.co.uk      | GBP |
| `CA`   | amazon.ca         | CAD |
| `DE`   | amazon.de         | EUR |
| `FR`   | amazon.fr         | EUR |
| `IT`   | amazon.it         | EUR |
| `ES`   | amazon.es         | EUR |
| `AU`   | amazon.com.au     | AUD |
| `IN`   | amazon.in         | INR |
| `MX`   | amazon.com.mx     | MXN |
| `BR`   | amazon.com.br     | BRL |
| `JP`   | amazon.co.jp      | JPY |
| `PL`   | amazon.pl         | PLN |

When supplied by the data source, price objects can include a `currency` code, display string, numeric `value`, and symbol. Glade API does not perform currency conversion.

## Pricing

Glade API charges **one unit per successful operation**. Errors are not charged. Every new account starts on the REST-only Hobby plan with **100 included units** and no credit card requirement.

View current plan limits and pricing at [gladeapi.com/pricing](https://gladeapi.com/pricing).
