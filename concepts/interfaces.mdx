Glade API exposes the same 17 Amazon operations through REST, GraphQL, and MCP. The underlying validation, caching, output contracts, and unit accounting are shared.

<Note>
  The Hobby plan includes REST only. Pay as you go, Premium 20K, and Enterprise plans include REST, GraphQL, and MCP.
</Note>

<Tabs>
  <Tab title="REST">
    ## REST

    REST uses `GET` endpoints under `https://gladeapi.com/api/amazon/`. Pass parameters in the query string and authenticate with `API-KEY` or a Bearer token.

    ```bash
    curl "https://gladeapi.com/api/amazon/product?asin=B0D1XD1ZV3&domain=US" \
      -H "API-KEY: YOUR_GLADE_API_KEY"
    ```

    REST is available on every plan and is the simplest interface for scripts and backend services.
  </Tab>

  <Tab title="GraphQL">
    ## GraphQL

    GraphQL accepts authenticated `POST` requests at `https://gladeapi.com/api/graphql`. Every query must contain exactly one root field, so it selects fields from one Glade operation rather than joining multiple operations.

    ```bash
    curl -X POST "https://gladeapi.com/api/graphql" \
      -H "API-KEY: YOUR_GLADE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"query":"query { amazonProduct(input: { asin: \"B0D1XD1ZV3\", domain: US }) { title price { value currency } isPrime } }"}'
    ```

    Authenticated schema introspection is supported through the same `POST` endpoint. There is no browser-based GraphQL playground at that URL.
  </Tab>

  <Tab title="MCP">
    ## MCP

    MCP exposes all 17 operations as read-only tools at `https://gladeapi.com/api/mcp`. The endpoint uses Streamable HTTP, implements the `2026-07-28` protocol revision, and includes stateless compatibility for 2025-era clients.

    MCP accepts `API-KEY`, `GLADE-API-KEY`, `X-API-KEY`, or `Authorization: Bearer` authentication. Use an MCP client that supports remote Streamable HTTP servers and custom request headers.

    Every tool result includes structured content and a JSON text representation. Tool annotations identify the operations as read-only and instruct clients to treat marketplace content as untrusted data.

    See [Connect AI agents](/guides/ai-agents) for setup and the exact tool names.
  </Tab>
</Tabs>

## Which interface should I use?

| Interface | Best for | Request |
|---|---|---|
| **REST** | Simple integrations and backend services | `GET https://gladeapi.com/api/amazon/*` |
| **GraphQL** | Selecting a subset of fields from one operation | `POST https://gladeapi.com/api/graphql` |
| **MCP** | AI agents and tool-use workflows | `POST https://gladeapi.com/api/mcp` |

Each successful operation costs one unit. Switching interfaces does not bypass plan entitlements, quotas, rate limits, or caching.
