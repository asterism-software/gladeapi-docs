---

The `/api/amazon/author` endpoint fetches an author's Amazon profile page by their author ASIN — returning their biography, profile image, and a paginated list of their published books with prices, ratings, and co-author information. Use this endpoint to build author spotlight pages, bookstore catalogs, or reading recommendation tools.

<Info>
  Author ASINs look like product ASINs (10-character alphanumeric) but resolve to author profile pages on Amazon. You can find an author's ASIN in their Amazon Author Page URL, e.g. `amazon.com/author/B00123ABCD`.
</Info>

## Request

<br />

**`GET https://api.glade.dev/api/amazon/author`**

<ParamField query="asin" type="string" required>
  The author's Amazon Author Page ASIN — a 10-character alphanumeric identifier. You can find it in the author's Amazon profile URL, e.g. `amazon.com/author/B00123ABCD`.
</ParamField>

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace to query. Accepted values: `US`, `UK`, `CA`, `DE`, `FR`, `IT`, `ES`, `AU`, `IN`, `MX`, `BR`, `JP`, `PL`. Defaults to `US` when omitted.
</ParamField>

<ParamField query="page" type="integer">
  The page number of the author's book listings to return. Must be `1` or greater. Omit to retrieve the first page.
</ParamField>

## Response

A successful response returns `data.amazonAuthor`.

<ResponseField name="data.amazonAuthor" type="object">
  <Expandable title="amazonAuthor">
    <ResponseField name="name" type="string">
      The author's full name as shown on their Amazon Author Page.
    </ResponseField>
    <ResponseField name="url" type="string">
      The canonical URL of the author's Amazon Author Page.
    </ResponseField>
    <ResponseField name="imageUrl" type="string">
      URL of the author's profile photo.
    </ResponseField>
    <ResponseField name="biography" type="string">
      The author's biographical text as written on their Amazon Author Page.
    </ResponseField>
    <ResponseField name="bookResults" type="object">
      <Expandable title="bookResults">
        <ResponseField name="results" type="array">
          <Expandable title="results[]">
            <ResponseField name="title" type="string">Book title.</ResponseField>
            <ResponseField name="url" type="string">Canonical Amazon product URL for the book.</ResponseField>
            <ResponseField name="asin" type="string">The book's Amazon Standard Identification Number.</ResponseField>
            <ResponseField name="price" type="object">
              <Expandable title="price">
                <ResponseField name="symbol" type="string">Currency symbol, e.g. `"$"`.</ResponseField>
                <ResponseField name="value" type="number">Numeric price value, e.g. `14.99`.</ResponseField>
                <ResponseField name="currency" type="string">ISO 4217 currency code, e.g. `"USD"`.</ResponseField>
                <ResponseField name="display" type="string">Formatted display string, e.g. `"$14.99"`.</ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="mainImageUrl" type="string">URL of the book cover image.</ResponseField>
            <ResponseField name="rating" type="number">Average customer rating (1–5).</ResponseField>
            <ResponseField name="ratingsTotal" type="integer">Total number of customer ratings.</ResponseField>
            <ResponseField name="isPrime" type="boolean">Whether the book is eligible for Amazon Prime.</ResponseField>
            <ResponseField name="sponsored" type="boolean">Whether the listing is a sponsored placement.</ResponseField>
            <ResponseField name="coupon" type="object | null">
              Active coupon object, or `null` if no coupon is present.
              <Expandable title="coupon">
                <ResponseField name="label" type="string">Coupon label text, e.g. `"Save 10%"`.</ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="authors" type="array">
              <Expandable title="authors[]">
                <ResponseField name="name" type="string">The author's name as listed on the book.</ResponseField>
                <ResponseField name="url" type="string">URL to the author's Amazon Author Page.</ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="pageInfo" type="object">
          <Expandable title="pageInfo">
            <ResponseField name="currentPage" type="integer">The page number returned.</ResponseField>
            <ResponseField name="totalPages" type="integer">Total number of book listing pages available.</ResponseField>
            <ResponseField name="totalResults" type="integer">Total number of books by this author.</ResponseField>
            <ResponseField name="hasNextPage" type="boolean">Whether a subsequent page exists.</ResponseField>
            <ResponseField name="hasPrevPage" type="boolean">Whether a previous page exists.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Curl example

```bash
curl --request GET \
  --url "https://api.glade.dev/api/amazon/author?asin=B00G0WYW28&domain=US&page=1" \
  --header "API-KEY: <your-api-key>"
```

## Error handling

If a required parameter is missing or invalid, the API returns a non-2xx status code with a JSON error body. Always check the `success` field before reading `data`.

| HTTP Status | Meaning |
|---|---|
| `400` | Bad request — a required parameter is missing or has an invalid value. |
| `401` | Unauthorized — your API key is missing or invalid. |
| `402` | Payment required — your plan does not cover this endpoint or your quota is exhausted. |
| `429` | Too many requests — you have exceeded your plan's rate limit. |
| `502` | Bad gateway — Amazon returned an unexpected response; retry with exponential back-off. |

### Example error response

```json
{
  "success": false,
  "errors": [
    {
      "code": 400,
      "message": "Missing required parameter: asin"
    }
  ]
}
```
