Retrieve every available variant for a given Amazon product — covering dimensions such as color, size, style, material, and more. Each variant in the response carries its own ASIN, display label, direct URL, attribute set, and current price, giving you everything you need to render a complete variant selector or compare pricing across options.

## Request

```http
GET https://api.glade.dev/api/amazon/product/variants
```

### Query Parameters

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace to query. Accepted values: `US` `UK` `CA` `DE` `FR` `IT` `ES` `AU` `IN` `MX` `BR` `JP` `PL`. Defaults to `US` when omitted.
</ParamField>

<ParamField query="asin" type="string">
  The Amazon Standard Identification Number of the product (e.g. `B09XS7JWHH`). Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="url" type="string">
  A full Amazon product URL. Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="gtin" type="string">
  A Global Trade Item Number (barcode) such as a UPC or EAN. Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

## Response

Variants are returned as an array under `data.amazonProduct.variants`.

<ResponseField name="data.amazonProduct.variants" type="object[]">
  <Expandable title="variant item fields" defaultOpen>
    <ResponseField name="asin" type="string">
      The unique ASIN for this specific variant, matching the pattern `^[A-Z0-9]{10}$`.
    </ResponseField>
    <ResponseField name="text" type="string">
      Human-readable display label for this variant (e.g. `Black / Large`).
    </ResponseField>
    <ResponseField name="url" type="string">
      Direct Amazon URL that links to this variant's listing.
    </ResponseField>
    <ResponseField name="attributes" type="object[]">
      <Expandable title="attribute item">
        <ResponseField name="name" type="string">
          Attribute dimension, e.g. `Color`, `Size`, or `Style`.
        </ResponseField>
        <ResponseField name="value" type="string">
          Attribute value for this variant, e.g. `Midnight Black` or `Extra Large`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="price" type="object">
      <Expandable title="price fields">
        <ResponseField name="symbol" type="string">
          Currency symbol, e.g. `$`.
        </ResponseField>
        <ResponseField name="value" type="number">
          Numeric price value, e.g. `279.99`.
        </ResponseField>
        <ResponseField name="currency" type="string">
          ISO 4217 currency code, e.g. `USD`.
        </ResponseField>
        <ResponseField name="display" type="string">
          Human-readable price string, e.g. `$279.99`.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Handling

All errors follow a consistent envelope. The HTTP status code mirrors the `code` field inside the `errors` array.

| Status | Meaning |
|--------|---------|
| `400`  | Bad request — a required parameter is missing or malformed. |
| `401`  | Unauthorized — your API key is missing or invalid. |
| `402`  | Payment required — your plan limit has been reached. |
| `429`  | Too many requests — you have exceeded the rate limit for your plan. |
| `502`  | Bad gateway — Amazon returned an unexpected response; retry with exponential back-off. |

```json
{
  "success": false,
  "errors": [
    {
      "code": 400,
      "message": "Missing required parameter: asin, url, or gtin must be provided"
    }
  ]
}
```

## curl Example

```bash
curl --request GET \
  --url 'https://api.glade.dev/api/amazon/product/variants?asin=B09XS7JWHH&domain=US' \
  --header 'API-KEY: YOUR_API_KEY'
```
