title: "GET /api/amazon/categories — Full Category Taxonomy"
sidebarTitle: "Category Taxonomy"

---

The `/api/amazon/categories` endpoint retrieves the full product category taxonomy for any supported Amazon marketplace. Each entry in the response includes a category ID, display name, URL, and a slash-separated breadcrumb path showing where it sits in the hierarchy. Use this endpoint to build category navigation menus, populate filter dropdowns, or discover valid category IDs for use with other endpoints.

<Tip>
  Use the category IDs returned by this endpoint with the `/api/amazon/search` and `/api/amazon/category` endpoints to filter results to a specific category.
</Tip>

## Request

<br />

**`GET https://api.glade.dev/api/amazon/categories`**

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace whose category taxonomy you want to retrieve. Accepted values: `US`, `UK`, `CA`, `DE`, `FR`, `IT`, `ES`, `AU`, `IN`, `MX`, `BR`, `JP`, `PL`. Defaults to `US` when omitted.
</ParamField>

## Response

A successful response returns `data.amazonProductCategoryTaxonomy`, an array of category objects covering both top-level departments and nested subcategories.

<ResponseField name="data.amazonProductCategoryTaxonomy" type="array">
  <Expandable title="amazonProductCategoryTaxonomy[]">
    <ResponseField name="id" type="string" required>
      The unique category identifier. Pass this value to the `/api/amazon/category` or `/api/amazon/search` endpoints to scope results to this category.
    </ResponseField>
    <ResponseField name="name" type="string" required>
      The human-readable display name of the category.
    </ResponseField>
    <ResponseField name="url" type="string" required>
      The canonical Amazon URL for this category browse page.
    </ResponseField>
    <ResponseField name="breadcrumbPath" type="string">
      A slash-separated string representing the category's position in the taxonomy hierarchy, e.g. `"Electronics > Headphones > Over-Ear Headphones"`. Top-level categories have a single-segment path.
    </ResponseField>
  </Expandable>
</ResponseField>

## Curl example

```bash
curl --request GET \
  --url "https://api.glade.dev/api/amazon/categories?domain=US" \
  --header "API-KEY: <your-api-key>"
```

## Error handling

If your request is malformed or your credentials are invalid, the API returns a non-2xx status code with a JSON error body. Always check the `success` field before iterating over `data`.

| HTTP Status | Meaning |
|---|---|
| `400` | Bad request — the `domain` value is not a recognized marketplace code. |
| `401` | Unauthorized — your API key is missing or invalid. |
| `429` | Too many requests — you have exceeded your plan's rate limit. |

### Example error response

```json
{
  "success": false,
  "errors": [
    {
      "code": 400,
      "message": "Missing required parameter: sellerId"
    }
  ]
}
```
