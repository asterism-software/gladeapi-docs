description: "Fetch all third-party seller offers for an Amazon product. Returns pricing, delivery, seller rating, and buybox status with pagination support."
---

Retrieve all third-party seller offers listed for a given Amazon product. For each offer you get the price, delivery details, seller profile (name, rating, feedback count), and whether that offer currently holds the buybox. Results are paginated, allowing you to walk through large offer sets with the `page` parameter.

## Request

```http
GET https://api.glade.dev/api/amazon/product/offers
```

### Query Parameters

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace to query. Accepted values: `US` `UK` `CA` `DE` `FR` `IT` `ES` `AU` `IN` `MX` `BR` `JP` `PL`. Defaults to `US` when omitted.
</ParamField>

<ParamField query="asin" type="string">
  The Amazon Standard Identification Number (e.g. `B09XS7JWHH`). Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="url" type="string">
  A full Amazon product URL. Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="gtin" type="string">
  A Global Trade Item Number (barcode). Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number of results to return. Minimum value is `1`.
</ParamField>

## Error Handling

All errors follow a consistent envelope. The HTTP status code mirrors the `code` field inside the `errors` array.

| Status | Meaning |
|--------|---------|
| `400`  | Bad request — a required parameter is missing or malformed. |
| `401`  | Unauthorized — your API key is missing or invalid. |
| `402`  | Payment required — your plan limit has been reached. |
| `429`  | Too many requests — you have exceeded the rate limit for your plan. |
| `502`  | Bad gateway — Amazon returned an unexpected response; retry with exponential back-off. |

```json
{
  "success": false,
  "errors": [
    {
      "code": 400,
      "message": "Missing required parameter: asin, url, or gtin must be provided"
    }
  ]
}
```

## curl Example

```bash
curl --request GET \
  --url 'https://api.glade.dev/api/amazon/product/offers?asin=B09XS7JWHH&domain=US&page=1' \
  --header 'API-KEY: YOUR_API_KEY'
```
