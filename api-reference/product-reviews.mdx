---
title: "GET /api/amazon/product/reviews — Fetch Product Reviews"
sidebarTitle: "Product Reviews"
description: "Retrieve paginated Amazon product reviews with filters for star rating, verified purchase status, and keyword search within review text."
---

Retrieve customer reviews for any Amazon product, with full control over filtering and pagination. You can narrow results by star rating, limit to verified purchases only, or search for a keyword within review text. The response includes both Amazon's hand-picked top reviews and a paginated list of all matching reviews — each with rating, body text, images, videos, and reviewer metadata.

## Request

```http
GET https://api.glade.dev/api/amazon/product/reviews
```

### Query Parameters

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace to query. Accepted values: `US` `UK` `CA` `DE` `FR` `IT` `ES` `AU` `IN` `MX` `BR` `JP` `PL`. Defaults to `US` when omitted.
</ParamField>

<ParamField query="asin" type="string">
  The Amazon Standard Identification Number (e.g. `B09XS7JWHH`). Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="url" type="string">
  A full Amazon product URL. Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="gtin" type="string">
  A Global Trade Item Number (barcode). Provide at least one of `asin`, `url`, or `gtin`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number of reviews to return. Minimum value is `1`.
</ParamField>

<ParamField query="onlyVerifiedReviews" type="boolean">
  When `true`, only reviews from verified purchasers are returned.
</ParamField>

<ParamField query="rating" type="string" default="ALL">
  Filter reviews by star rating. Accepted values: `ALL` `FIVE_STAR` `FOUR_STAR` `THREE_STAR` `TWO_STAR` `ONE_STAR`.
</ParamField>

<ParamField query="search" type="string">
  Keyword to search for within review text. Returns only reviews that contain the search term.
</ParamField>

## Response

The response is nested under `data.amazonProduct` and contains two distinct review lists.

<ResponseField name="data.amazonProduct" type="object">
  <Expandable title="amazonProduct fields" defaultOpen>
    <ResponseField name="topReviews" type="object[]">
      Amazon's featured reviews for this product, independent of pagination. Each item shares the same shape as a paginated review.
      <Expandable title="review item fields">
        <ResponseField name="id" type="string">Unique identifier for the review.</ResponseField>
        <ResponseField name="title" type="string">Review headline.</ResponseField>
        <ResponseField name="body" type="string">Full review text.</ResponseField>
        <ResponseField name="imageUrls" type="string[]">Array of image URLs attached to the review.</ResponseField>
        <ResponseField name="videos" type="object[]">
          <Expandable title="video item">
            <ResponseField name="posterImageUrl" type="string">Thumbnail image URL for the video.</ResponseField>
            <ResponseField name="url" type="string">Direct URL to the video content.</ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="rating" type="number">Star rating given by the reviewer, 1–5.</ResponseField>
        <ResponseField name="helpfulVotes" type="integer">Number of customers who marked this review as helpful.</ResponseField>
        <ResponseField name="verifiedPurchase" type="boolean">`true` if Amazon has verified the reviewer purchased the product.</ResponseField>
        <ResponseField name="reviewer" type="object">
          <Expandable title="reviewer fields">
            <ResponseField name="id" type="string">Reviewer's Amazon profile ID.</ResponseField>
            <ResponseField name="name" type="string">Reviewer's display name.</ResponseField>
            <ResponseField name="url" type="string">URL to the reviewer's Amazon profile.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="reviewsPaginated" type="object">
      <Expandable title="reviewsPaginated fields">
        <ResponseField name="reviews" type="object[]">
          Paginated list of reviews matching any applied filters. Each item has the same shape as a `topReviews` item.
        </ResponseField>
        <ResponseField name="pageInfo" type="object">
          <Expandable title="pageInfo fields">
            <ResponseField name="currentPage" type="integer">The page number returned.</ResponseField>
            <ResponseField name="totalPages" type="integer">Total number of pages available.</ResponseField>
            <ResponseField name="totalResults" type="integer">Total number of matching reviews.</ResponseField>
            <ResponseField name="hasNextPage" type="boolean">`true` if a subsequent page exists.</ResponseField>
            <ResponseField name="hasPrevPage" type="boolean">`true` if a previous page exists.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Handling

All errors follow a consistent envelope. The HTTP status code mirrors the `code` field inside the `errors` array.

| Status | Meaning |
|--------|---------|
| `400`  | Bad request — a required parameter is missing or malformed. |
| `401`  | Unauthorized — your API key is missing or invalid. |
| `402`  | Payment required — your plan limit has been reached. |
| `429`  | Too many requests — you have exceeded the rate limit for your plan. |
| `502`  | Bad gateway — Amazon returned an unexpected response; retry with exponential back-off. |

```json
{
  "success": false,
  "errors": [
    {
      "code": 400,
      "message": "Missing required parameter: asin, url, or gtin must be provided"
    }
  ]
}
```

## curl Example

```bash
curl --request GET \
  --url 'https://api.glade.dev/api/amazon/product/reviews?asin=B09XS7JWHH&domain=US&rating=FIVE_STAR&onlyVerifiedReviews=true&page=1' \
  --header 'API-KEY: YOUR_API_KEY'
```
