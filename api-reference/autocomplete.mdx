The autocomplete endpoint returns Amazon's real-time search suggestions for a partial query string. You can use it to power a type-ahead input in your UI, help users discover popular related searches, or pre-populate a search bar as they type. Optionally scope suggestions to a specific category to keep results relevant.

## Request

<ParamField query="searchTerm" type="string" required>
  The partial or full search string to get suggestions for (e.g., `"wireless ear"`).
</ParamField>

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace to query. Supported values: `US`, `UK`, `CA`, `DE`, `FR`, `IT`, `ES`, `AU`, `IN`, `MX`, `BR`, `JP`, `PL`. Defaults to `US`.
</ParamField>

<ParamField query="category" type="string">
  Restrict autocomplete suggestions to a specific Amazon category. Pass a category name or ID to focus results (e.g., `"electronics"`).
</ParamField>

### Example request

```bash
curl "https://api.glade.dev/api/amazon/autocomplete?searchTerm=wireless%20ear&domain=US" \
  -H "API-KEY: YOUR_API_KEY"
```

---

## Response

A successful response returns `data.amazonSearchAutocompleteResults` — a flat array of suggestion objects, ordered by Amazon's relevance ranking.

<ResponseField name="data.amazonSearchAutocompleteResults" type="array">
  Ordered list of autocomplete suggestion objects.

  <Expandable title="amazonSearchAutocompleteResults[]">
    <ResponseField name="suggestion" type="string">
      A suggested search term derived from the partial query (e.g., `"wireless earbuds"`).
    </ResponseField>
  </Expandable>
</ResponseField>

### Example response

```json
{
  "data": {
    "amazonSearchAutocompleteResults": [
      { "suggestion": "wireless earbuds" },
      { "suggestion": "wireless earbuds noise cancelling" },
      { "suggestion": "wireless earbud case" },
      { "suggestion": "wireless ear muffs" },
      { "suggestion": "wireless earbuds for kids" },
      { "suggestion": "wireless earbuds waterproof" }
    ]
  }
}
```

## Error handling

The `searchTerm` query parameter is required. Sending a request without it returns a `400` error. Requests with an invalid or missing API key return `401`.

```json
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "Query parameter 'searchTerm' is required.",
    "status": 400
  }
}
```

| Status | Meaning |
|--------|---------|
| `400` | Missing or invalid query parameters |
| `401` | Missing or invalid `API-KEY` / Bearer token |
| `429` | Rate limit exceeded |
| `500` | Upstream Amazon error or internal server error |
