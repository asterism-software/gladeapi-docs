The `/api/amazon/seller` endpoint returns a seller's full profile from any supported Amazon marketplace — including their display name, logo, phone number, aggregate rating, and a paginated list of their active product listings. Use this endpoint to power seller directory pages, due-diligence tools, or competitive-analysis dashboards.

## Request

<br />

**`GET https://api.glade.dev/api/amazon/seller`**

<ParamField query="sellerId" type="string" required>
  The Amazon seller identifier for the seller you want to look up. You can find this value in a seller's Amazon profile URL — it appears as the `seller` query parameter, e.g. `amazon.com/sp?seller=A2L77EE7U53NWQ`.
</ParamField>

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace to query. Accepted values: `US`, `UK`, `CA`, `DE`, `FR`, `IT`, `ES`, `AU`, `IN`, `MX`, `BR`, `JP`, `PL`. Defaults to `US` when omitted.
</ParamField>

<ParamField query="page" type="integer">
  The page number of the seller's product listings to return. Must be `1` or greater. Omit to retrieve the first page.
</ParamField>

## Response

A successful response returns `data.amazonSeller`.

<ResponseField name="data.amazonSeller" type="object">
  <Expandable title="amazonSeller">
    <ResponseField name="sellerId" type="string">
      The unique Amazon seller identifier.
    </ResponseField>
    <ResponseField name="name" type="string">
      The seller's display name as shown on their Amazon storefront.
    </ResponseField>
    <ResponseField name="logoUrl" type="string">
      URL of the seller's logo image, if available.
    </ResponseField>
    <ResponseField name="phone" type="string">
      The seller's listed contact phone number, if provided.
    </ResponseField>
    <ResponseField name="rating" type="number">
      The seller's aggregate feedback rating, on a scale of 1–5.
    </ResponseField>
    <ResponseField name="about" type="string">
      The seller's self-written about/description text from their storefront.
    </ResponseField>
    <ResponseField name="productResults" type="object">
      <Expandable title="productResults">
        <ResponseField name="results" type="array">

            <ResponseField name="title" type="string">Product title.</ResponseField>
            <ResponseField name="url" type="string">Canonical Amazon product URL.</ResponseField>
            <ResponseField name="asin" type="string">Amazon Standard Identification Number.</ResponseField>
            <ResponseField name="price" type="object">
              <Expandable title="price">
                <ResponseField name="symbol" type="string">Currency symbol, e.g. `"$"`.</ResponseField>
                <ResponseField name="value" type="number">Numeric price value, e.g. `35.99`.</ResponseField>
                <ResponseField name="currency" type="string">ISO 4217 currency code, e.g. `"USD"`.</ResponseField>
                <ResponseField name="display" type="string">Formatted display string, e.g. `"$35.99"`.</ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="mainImageUrl" type="string">URL of the primary product image.</ResponseField>
            <ResponseField name="rating" type="number">Average customer rating (1–5).</ResponseField>
            <ResponseField name="ratingsTotal" type="integer">Total number of customer ratings.</ResponseField>
            <ResponseField name="isPrime" type="boolean">Whether the product is eligible for Amazon Prime.</ResponseField>
            <ResponseField name="sponsored" type="boolean">Whether the listing is a sponsored placement.</ResponseField>
            <ResponseField name="coupon" type="object | null">
              Active coupon object, or `null` if no coupon is present.
              <Expandable title="coupon">
                <ResponseField name="label" type="string">Coupon label text, e.g. `"Save 5%"`.</ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="pageInfo" type="object">
          <Expandable title="pageInfo">
            <ResponseField name="currentPage" type="integer">The page number returned.</ResponseField>
            <ResponseField name="totalPages" type="integer">Total number of listing pages available.</ResponseField>
            <ResponseField name="totalResults" type="integer">Total product listing count for this seller.</ResponseField>
            <ResponseField name="hasNextPage" type="boolean">Whether a subsequent page exists.</ResponseField>
            <ResponseField name="hasPrevPage" type="boolean">Whether a previous page exists.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Curl example

```bash
curl --request GET \
  --url "https://api.glade.dev/api/amazon/seller?sellerId=A2L77EE7U53NWQ&domain=US&page=1" \
  --header "API-KEY: <your-api-key>"
```

## Error handling

If a required parameter is missing or invalid, the API returns a non-2xx status code with a JSON error body. Always check the `success` field before reading `data`.

| HTTP Status | Meaning |
|---|---|
| `400` | Bad request — a required parameter is missing or has an invalid value. |
| `401` | Unauthorized — your API key is missing or invalid. |
| `402` | Payment required — your plan does not cover this endpoint or your quota is exhausted. |
| `429` | Too many requests — you have exceeded your plan's rate limit. |
| `502` | Bad gateway — Amazon returned an unexpected response; retry with exponential back-off. |

### Example error response

```json
{
  "success": false,
  "errors": [
    {
      "code": 400,
      "message": "Missing required parameter: sellerId"
    }
  ]
}
```
