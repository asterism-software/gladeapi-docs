The `/api/amazon/category` endpoint returns the full details of a single Amazon product category — including its subcategories, a paginated list of products, and metadata such as its breadcrumb path. Use this endpoint to power category browse pages, populate product grids, or walk the Amazon category tree by following the `subcategories` array into deeper levels.

## Request

<br />

**`GET https://api.glade.dev/api/amazon/category`**

<ParamField query="categoryId" type="string" required>
  The Amazon category node ID you want to browse. Retrieve valid IDs from the `/api/amazon/categories` endpoint. For example, `7141123011` corresponds to the Headphones category on amazon.com.
</ParamField>

<ParamField query="domain" type="string" default="US">
  The Amazon marketplace to query. Accepted values: `US`, `UK`, `CA`, `DE`, `FR`, `IT`, `ES`, `AU`, `IN`, `MX`, `BR`, `JP`, `PL`. Defaults to `US` when omitted.
</ParamField>

<ParamField query="page" type="integer">
  The page number of product results to return. Must be `1` or greater. Omit to retrieve the first page.
</ParamField>

<ParamField query="sort" type="string">
  The sort order applied to product results. Common values include `featured`, `price-asc-rank`, `price-desc-rank`, `review-rank`, and `date-desc-rank`. When omitted, Amazon's default featured sort is used.
</ParamField>

## Response

A successful response returns `data.amazonProductCategory`.

<ResponseField name="data.amazonProductCategory" type="object">
  <Expandable title="amazonProductCategory">
    <ResponseField name="id" type="string">
      The category node ID matching the `categoryId` you requested.
    </ResponseField>
    <ResponseField name="name" type="string">
      The human-readable display name of the category.
    </ResponseField>
    <ResponseField name="url" type="string">
      The canonical Amazon URL for this category browse page.
    </ResponseField>
    <ResponseField name="breadcrumbPath" type="string">
      A slash-separated string representing the category's position in the taxonomy, e.g. `"Electronics > Headphones > Over-Ear Headphones"`.
    </ResponseField>
    <ResponseField name="subcategories" type="array">
      <Expandable title="subcategories[]">
        <ResponseField name="id" type="string">Subcategory node ID.</ResponseField>
        <ResponseField name="name" type="string">Subcategory display name.</ResponseField>
        <ResponseField name="url" type="string">Canonical Amazon URL for the subcategory.</ResponseField>
        <ResponseField name="breadcrumbPath" type="string">Full breadcrumb path for the subcategory.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="productResults" type="object">
      <Expandable title="productResults">
        <ResponseField name="results" type="array">
          <Expandable title="results[]">
            <ResponseField name="title" type="string">Product title.</ResponseField>
            <ResponseField name="url" type="string">Canonical Amazon product URL.</ResponseField>
            <ResponseField name="asin" type="string">Amazon Standard Identification Number.</ResponseField>
            <ResponseField name="price" type="object">
              <Expandable title="price">
                <ResponseField name="symbol" type="string">Currency symbol, e.g. `"$"`.</ResponseField>
                <ResponseField name="value" type="number">Numeric price value, e.g. `279.99`.</ResponseField>
                <ResponseField name="currency" type="string">ISO 4217 currency code, e.g. `"USD"`.</ResponseField>
                <ResponseField name="display" type="string">Formatted display string, e.g. `"$279.99"`.</ResponseField>
              </Expandable>
            </ResponseField>
            <ResponseField name="mainImageUrl" type="string">URL of the primary product image.</ResponseField>
            <ResponseField name="rating" type="number">Average customer rating (1–5).</ResponseField>
            <ResponseField name="ratingsTotal" type="integer">Total number of customer ratings.</ResponseField>
            <ResponseField name="isPrime" type="boolean">Whether the product is eligible for Amazon Prime.</ResponseField>
            <ResponseField name="sponsored" type="boolean">Whether the listing is a sponsored placement.</ResponseField>
            <ResponseField name="coupon" type="object | null">
              Active coupon object, or `null` if no coupon is present.
              <Expandable title="coupon">
                <ResponseField name="label" type="string">Coupon label text, e.g. `"Save 15%"`.</ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="pageInfo" type="object">
          <Expandable title="pageInfo">
            <ResponseField name="currentPage" type="integer">The page number returned.</ResponseField>
            <ResponseField name="totalPages" type="integer">Total number of product pages available for this category.</ResponseField>
            <ResponseField name="totalResults" type="integer">Estimated total number of products in this category.</ResponseField>
            <ResponseField name="hasNextPage" type="boolean">Whether a subsequent page exists.</ResponseField>
            <ResponseField name="hasPrevPage" type="boolean">Whether a previous page exists.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Curl example

```bash
curl --request GET \
  --url "https://api.glade.dev/api/amazon/category?categoryId=7141123011&domain=US&page=1&sort=review-rank" \
  --header "API-KEY: <your-api-key>"
```

## Error handling

If a required parameter is missing or invalid, the API returns a non-2xx status code with a JSON error body. Always check the `success` field before reading `data`.

| HTTP Status | Meaning |
|---|---|
| `400` | Bad request — a required parameter is missing or has an invalid value. |
| `401` | Unauthorized — your API key is missing or invalid. |
| `402` | Payment required — your plan does not cover this endpoint or your quota is exhausted. |
| `429` | Too many requests — you have exceeded your plan's rate limit. |
| `502` | Bad gateway — Amazon returned an unexpected response; retry with exponential back-off. |

### Example error response

```json
{
  "success": false,
  "errors": [
    {
      "code": 400,
      "message": "Missing required parameter: categoryId"
    }
  ]
}
```
